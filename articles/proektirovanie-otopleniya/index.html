Проектирование отопления: зачем нужен проект

Многие считают, что проект отопления — это лишняя трата денег. Но на деле правильное проектирование экономит время и деньги в будущем. Без проекта вы рискуете получить неэффективную систему и переплатить за переделку.

Зачем нужен проект отопления

  1. Расчёт мощности — чтобы котёл не был слишком слабым или мощным
  2. Гидравлический расчёт — чтобы все радиаторы получали одинаковое количество тепла
  3. Подбор оборудования — оптимальное соотношение цена/качество
  4. Смета — точная стоимость работ без сюрпризов
  5. Согласование — необходимое для газового оборудования

Что будет без проекта

  • Неправильная мощность котла — перерасход газа или холодные комнаты
  • Неравномерный нагрев — одни радиаторы горячие, другие холодные
  • Протечки — неправильный подбор труб и фитингов
  • Переплата — покупка лишнего оборудования
  • Переделка — дополнительные расходы на исправление ошибок

Этапы проектирования отопления

Работа над проектом состоит из пяти последовательных этапов. Каждый этап фиксируется документами, которые затем передаются монтажникам.

  1. Теплоотдача помещения. Инженер рассчитывает теплопотери для каждой комнаты с учётом утепления, окон, ориентации по сторонам света.
  2. Подбор схемы разводки. Тройниковая или коллекторная, однотрубная или двухтрубная — зависит от площади и планировки.
  3. Гидравлический расчёт. Определяются диаметры труб, производительность насосов, давление в контурах.
  4. Подбор оборудования. Котёл, коллекторы, радиаторы, трубы, арматура — по расчётным параметрам.
  5. Рабочая документация. Схемы, спецификации, смета — всё, что нужно для монтажа.

Тепловой расчёт: как считаем мощность

Тепловой расчёт — это определение, сколько энергии нужно, чтобы поддерживать комфортную температуру в каждом помещении.

Базовая формула: Q = V × ΔT × k, где:

  • V — объём помещения (м³)
  • ΔT — разница температур внутри (+22°C) и снаружи (для СПб зимой −25°C)
  • k — коэффициент теплопотерь стен, окон, потолка

Пример для СПб: для дома 150 м² с высотой потолка 2,7 м расчётная мощность ~18 кВт. Сюда входит отопление + ГВС + запас на экстремальные морозы.

Гидравлический расчёт: балансировка системы

Гидравлический расчёт определяет, какой диаметр труб нужен, чтобы каждый радиатор получал одинаковое количество тепла. Без него ближние к котлу батареи будут кипеть, а дальние — холодные.

Результат расчёта:

  • Диаметры труб на каждой ветке (обычно 20-32 мм)
  • Производительность циркуляционного насоса
  • Установка балансировочных клапанов
  • Схема подключения коллекторов

Проект для газовой службы

Если в доме будет газовый котёл — проект обязателен по закону. Газовая служба не даст разрешение на подключение без утверждённого проекта.

Что нужно для проекта газификации:

  • План дома с расположением котельной
  • Паспорт на котёл
  • Схема дымохода
  • Расчёт потребления газа

Мы делаем проекты, которые принимает «Петербурггаз» и газовые службы Ленобласти — с учётом их актуальных требований.

Часто задаваемые вопросы

Обязательно ли делать проект отопления?
Для газового оборудования — обязательно (требование газовой службы). Для автономных систем — не обязательно, но настоятельно рекомендуем. Проект экономит 20-30% бюджета за счёт правильного подбора оборудования.
Можно ли сделать проект самостоятельно?
Теоретически — да, но без опыта вы допустите ошибки. Тепловой и гидравлический расчёт требуют знаний и software. Ошибки в проекте обходятся дороже, чем стоимость проекта.
Когда делать проект — до или после строительства?
До или во время строительства. Так вы заложите нужные отверстия в стенах, предусмотрите места для оборудования. После строительства — сложнее и дороже.
Что нужно для начала проектирования?
План дома с размерами, этажность, расположение окон и дверей. Желательно — план участка для привязки к газовой магистрали. Если дома ещё нет — план от архитектора.
Проект входит в стоимость монтажа?
Нет, проект — отдельная услуга. Но если заказываете монтаж у нас, стоимость проекта вычитается из стоимости работ. По сути — проект бесплатно при заказе монтажа.
Нужен ли проект для газовой службы?
Да, для подключения газового котла проект обязателен по закону. Газовая служба не даст разрешение без утверждённого проекта с учётом их требований. Мы делаем проекты, которые принимает «Петербурггаз» и газовые службы Ленобласти.
Что такое тепловой расчёт в проекте?
Тепловой расчёт — определение теплопотерь каждого помещения с учётом утепления, окон, ориентации по сторонам света. По результатам подбирается мощность котла и количество/размеры радиаторов. Для СПб расчёт ведётся с учётом зимней температуры −25°C.
