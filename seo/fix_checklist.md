# Чек-лист срочных фиксов

## 🔴 Критичные (исправить сегодня)

### 1. Форма обратной связи не работает
- **Проблема:** Форма на сайте не отправляет данные
- **Решение:** Настроить Formspree (endpoint: xrewrewb)
- **Действие:** Добавить action="https://formspree.io/f/xrewrewb" в форму

### 2. API-ключ OpenRouter в коде
- **Проблема:** Ключ открыто виден в JavaScript
- **Решение:** Перенести на backend
- **Действие:** Создать прокси-сервер или использовать env variables

## 🟡 Важные (исправить на этой неделе)

### 3. Оптимизация изображений
- **Проблема:** Некоторые изображения больше 500 КБ
- **Решение:** Сжать через TinyPNG
- **Действие:** Проверить все изображения и сжать

### 4. Добавить JSON-LD разметку
- **Проблема:** Нет структурированных данных
- **Решение:** Добавить LocalBusiness schema
- **Действие:** Вставить JSON-LD в head

### 5. Настроить отправку форм
- **Проблема:** Заявки не уходят на почту
- **Решение:** Настроить Formspree или backend
- **Действие:** Добавить action и method="POST"
